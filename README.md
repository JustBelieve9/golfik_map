# Golf 7.5 CZCA — справочник

Личный справочник по конкретной машине (VIN `WVWZZZAUZKP041455`): двигатель CZCA,
блоки управления, предохранители блока C, заводские PR-коды, каталог деталей ETKA,
доработки и журнал трат. 253 узла, 318 связей, 192 PR-кода.

Источник данных — старый хэндоф в `golf_handoff/golf_handoff2/` (не трогать,
это архив с ETKA-скриншотами и мануалом). Всё остальное собирается из него.

## Два формата

| | Что | Как открыть |
|---|---|---|
| **Полная версия** | `site/` — многофайловая, с графом связей | GitHub Pages (см. ниже) |
| **Офлайн-версия** | `golf-offline.html` в корне репозитория | Скачать на телефон, открыть любым браузером — работает без интернета, ни одного внешнего запроса |

Обе версии собираются из одного источника `build/graph.json` командой:

```bash
python3 build/build.py
```

## Разделы сайта

`#/` обзор · `#/engine` двигатель и мануал · `#/ecu` блоки управления ·
`#/fuses` предохранители · **`#/fuses/pro`** расширенный режим (фильтры по
статусу/клемме/номиналу, поиск, карта блока) · `#/pr` PR-коды · `#/parts`
каталог ETKA · `#/mods` доработки · `#/journal` журнал и траты ·
`graph.html` — радиальный граф всех связей (только полная версия, в офлайн-файле
его нет — тяжёлый и на телефоне не нужен).

## Деплой на GitHub Pages

Settings → Pages → Source: ветка `main`, папка `/site`.

`site/golf-offline.html` тоже попадёт на Pages — можно давать прямую ссылку
для скачивания на телефон без похода в репозиторий.

## Обновление данных

Данные — единый JSON `build/graph.json` (`nodes`, `links`, `pr`). Правишь его
руками или скриптом, потом:

```bash
python3 build/build.py
```

Скрипт проверяет целостность (нет висячих ссылок, у всех предохранителей есть
статус) и пересобирает оба формата. Если нужно заново вытащить граф из старого
монолита `golf_handoff/golf_handoff2/golf_map_offline_LATEST.html`:

```bash
python3 build/build.py --extract
```

## Устройство

- `site/assets/tokens.css` — палитра OKLCH (тёмная по умолчанию, светлая через
  переключатель в шапке), `tokens.css` в корне — её копия для переносимости.
- `site/assets/app.css` / `app.js` — вёрстка и вся логика, ноль зависимостей,
  hash-роутинг.
- `site/assets/fonts/` — Manrope + IBM Plex Sans + JetBrains Mono, кириллица +
  латиница, self-hosted (~145 КБ).
- `site/assets/graph.js` + `d3.v7.min.js` — радиальная кладограмма для
  `graph.html`, детерминированная раскладка (не физическая симуляция).
- `build/build.py` — сборка; инлайнит шрифты как base64 в офлайн-версию.
