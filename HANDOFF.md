# Хэндоф: Golf 7.5 CZCA — проект

Дата хэндофа: 2026-08-12 (обновлено после сверки с GitHub). Машина: VW Golf 7.5
(Mk7.5 facelift), тип BQ1/BQ12HZ, VIN WVWZZZAUZKP041455, двигатель 1.4 TSI
CZCA (92kW, EA211), DSG 0CW DQ200-7F, FWD. Дата производства 02.11.2018,
завод Zwickau/Mosel, изначально украинский рынок.

Ключевые PR-коды (подтверждены по стикеру + ETKA): UC7 (ППД, +~15мм), PSW
(усиленная подвеска), 1KE (задние диски + электромех. стояночник), 1Y3 (XDS,
не механический LSD), 8Z5 (охлаждение — не hot-country), 0Y3 (холодная
калибровка), 9AK/KH6 (Climatronic).

## Активные проекты и принятые решения

### Радиатор
Выбран NRF 58398 (448мм, паяные соты, 24мм) — совпадает по физическому
замеру и по типу конструкции. OEM-номер подтверждён через ETKA по VIN:
5Q0121251EA (семейство 448мм).
Отклонены: Valeo 735556 (механически завальцован), Nissens 606218 (438мм —
не тот размер), Mahle CR 2423 000S (размеры под 2.0T).

### Охлаждающая жидкость
Спецификация — VW TL 774 J (G13), lobrid/Si-OAT, на пропиленгликоле, объём
системы ~8л. Рекомендованы Febi 38200/38201 (G 013 A8J M1) или оригинал VAG
G 013 A8J M1. Сейчас в системе красно-розовая жидкость (похоже на G12/G12+,
для доливки совместима, но не соответствует целевой спецификации).
CoolStream Premium NRC G13 отклонён — допуски Renault-Nissan, чистый OAT, нет
сертификации VW TL 774-J.

### Поездка в Казахстан (степь, район озера Балхаш)
Подготовка: чистка радиатора/конденсора кондиционера, проверка концентрации
антифриза, проверка хладагента. Система охлаждения — не hot-country спека
(8Z5), это железо, кодированием не меняется.
Тент для ночёвки в машине: свободностоящий двускатный тент на 2 стойках,
полотно ~3×4м (150–180 г/м², светоотражающее), обычные треккинговые палки
2–2.2м достаточны, если закрывать только крышу и стёкла (без боковой тени).
Плюс отражающая шторка на лобовое.

### Пружины (занижение)
Выбраны OEM Eurosport 5G4071677D (для двигателей ≥90кВт, макс. нагрузка на
переднюю ось ≤1010кг), ~-30мм от базы ППД (реальное занижение от текущей
дорожной просвета ~30мм).
Eibach Pro-Kit отклонён — калибровка от euro-базы даёт эффективное занижение
~45-50мм на этой машине, риск пробоя на штатных амортизаторах без замены
отбойников и амортизаторов.

### DSG-прошивка
Мехатроник 0CW300041N, 0AM927769E H05, текущая прошивка 1603 (OJAD),
доступно обновление до 1607 (RJAD) для TSI-варианта. FRF-файлы полностью
зашифрованы, нужен профессиональный инструмент (Autotuner, KESS3, ECUTools +
WinOLS с DAMOS).

### На рассмотрении
Камера в бейдж багажника, кодирование VCDS/OBDeleven (комфортный поворотник,
качающаяся стрелка, амбиентная подсветка, авто-запирание дверей, датчик
дождя, авто-складывание зеркал), цифровая приборка, Park Pilot, ACC.

## Ключевые выводы (принципы работы)

- **Не доверять одному источнику по каталогу.** По радиатору был конфликт
  между ETKA по VIN (5Q0121251EA, семейство 448мм) и листингом немецкого
  разборщика по тому же коду двигателя (узкое семейство). Решает физический
  замер.
- **PR-код платформы важен для поиска деталей.** UC7 — код MQB-эры для ППД;
  старый PQ-код 1JB для этой машины не актуален. Общие гайды по Golf 7 могут
  ссылаться не на те коды.
- **База ППД сдвигает реальное занижение.** Любые пружины "-30мм" нужно
  сверять с базой отсчёта производителя — Eurosport считает от ППД, Eibach —
  от euro-базы, разница ~15-20мм в реальном результате.
- **Предположение про "жаркий" вентилятор было неверным.** У PR-кодов для
  жаркого климата (8Z6/8Z9) вентиляторы Brose *меньше* (DA/DG, 410мм), не
  больше. Установленный DE-вариант (440мм Magna, 400Вт) — уже максимум для
  этого движка/климат-исполнения.
- **Маркировка "G13" на упаковке не гарантирует допуск VW.** У CoolStream
  "G13" были только допуски Renault-Nissan, нужно явно проверять VW TL 774-J
  и lobrid-состав.
- **Более низкая точка замерзания ≠ лучше.** Перенасыщение антифриза
  ухудшает теплоотвод, руководство VW прямо предупреждает против этого.
- **ZIC предпочтительнее Lukoil в текущих условиях** — Lukoil
  переформулировал состав после 2022 из-за проблем с поставкой присадок,
  ZIC стабильнее. Оба имеют допуск VW 504.00/507.00. Премиум-бренды (Motul,
  Liqui Moly) не оправданы при интервале замены 5000–7000 км.
- **Цепь плафона багажника одновременно сигнальная линия.** Нельзя питать
  доп. нагрузку напрямую от плафона — использовать только как триггер для
  реле/MOSFET.
- **GitHub-репозиторий может разъезжаться по веткам без явного намерения.**
  Загрузка файла через веб-интерфейс GitHub на "не той" ветке создаёт
  разъезд, который потом надо мержить руками — сверять `main` и
  рабочие ветки перед тем как считать что-то "уже залито".

## Инструменты и источники

ETKA (легитимный доступ, установка + web) — основной источник номеров
деталей. ELSA — сервисная документация VW. VCDS/OBDeleven — кодирование и

поиск и цены деталей (РФ). drive2.ru — референс сообщества. SSP 511 —
корректный заводской референс по двигателю CZCA.

## Как продолжать в Claude Code

1. Открыть эту папку как рабочую директорию.
2. Проверить, смёржен ли `onefilebranch` в `main` на GitHub (см. команду
   выше). Если нет — довести до конца по шагам, описанным в разделе про
   граф-справочник выше.
3. После успешного мержа `golf_data.js` в `main` больше не нужен — можно
   удалить из репозитория для порядка.
4. `etka_screenshots/` — сырьё для дальнейшего OCR/сверки, если граф будет
   пополняться новыми деталями.
5. Активные открытые задачи с физической проверкой: замена радиатора,
   замена ОЖ на G13, установка пружин Eurosport, подготовка к поездке в
   Казахстан.
